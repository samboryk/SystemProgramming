# SystemProgramming

Навчальний проект з курсу "Системне програмування".

## Тема: Системи контролю версій (Git)

Веб-сторінка призначена для вивчення та опрацювання теми **Git**:
- Коротка інформація про системи контролю версій (СКВ) та історію створення Git (матеріали Вікіпедії).
- Основні можливості та ключові переваги використання Git.
- 10 базових команд із коментарями та прикладами використання.
- Розділ для розміщення та перегляду сертифіката проходження курсу по Git.
- Список перевірених джерел інформації та корисних посилань.
- Інтерактивне бічне меню для перегляду та динамічного додавання навчальних тем.

## Структура проекту
```
├── index.html        # Головна розмітка сайту
├── style.css         # Стилі інтерфейсу (адаптивний дизайн, темні акценти)
├── script.js         # Інтерактивність (бокове меню, додавання тем, копіювання команд)
└── README.md         # Опис проекту
```

## Швидкий старт
Відкрийте файл `index.html` у будь-якому сучасному веб-браузері (Chrome, Firefox, Edge).
